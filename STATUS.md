# Status

Last updated 2026-09-19. Private for now; intended to be open-sourced.

## Where it stands

- Format draft **0.3**. Five parts (space, thesis, open problems, roadmap, terms), a masthead, and four supporting documents. One YAML spec per part in `spec/`; blank templates in `formats/` are generated by `build.py`.
- `lint.py`: structural checks, exits non-zero on errors. Tested against blank templates (fails), a synthetic filled charter (passes), a dangling trace (fails), and one real charter.
- `render.py`: builds one self-contained HTML page from a charter directory. The tree is inline SVG when Playwright is available at build time.
- `.claude/skills/review-charter`: used once, on the first real charter. Its feedback on itself was folded back in.
- `reviews/2026-09-19-panel.md`: the three-seat review (role-played by AI agents) that shaped v0.2.

## Used in anger once

The agentic research program's charter is the only charter written in this format. Writing it changed the format four times: card-only sections counted as empty; items past research must carry an appetite, a date and an owner; premises may depend on each other; undecided markers are counted. Expect more of this with a second charter.

## Untested

- The supporting document formats (review note, discovery summary, closing report) have never been filled in.
